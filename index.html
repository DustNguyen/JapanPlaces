How to Use Japan Places

1. Set your name when prompted. Your name appears in the Source column when you add or edit places.

2. Use Find Places first for planning.

Focus flow: search by keyword, then narrow by Area and Purpose, then sort results to plan route order.

3. Add new Area or Purpose in Manage Area / Purpose Options before adding places.

4. Add places, paste/upload photos, and use Edit to keep details current.

5. Use map preview + Google Maps link to navigate.
